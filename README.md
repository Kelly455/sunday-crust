# Sunday Crust

Landing page for a fictional Nashville bakery. Built with plain HTML, CSS and JavaScript, with no frameworks or libraries.

**Goal of the page:** get a visitor to place an online order.

**Live site:** https://kelly455.github.io/sunday-crust/

## Features
- Mobile-first responsive layout (tested at 375px and 1440px)
- Live order total with validated form (quantities, name, 10-digit phone, pickup date)
- Pickup rules enforced in JS: next-morning minimum (order by 6pm), closed Mondays
- Product cards pre-select the item in the order form
- Keyboard-visible focus states and reduced-motion support

## Notes
- Demo only: no payment is processed and no order is sent anywhere.
- Reviews are labeled sample reviews.
